## Порядок работы агента

1. **Холодный старт:** прочитать этот файл, `CURRENT_STATE.md`, `plans/feature_list.json`.
   Запустить полную проверку. **Красная база = не начинать новую фичу.**
2. **Работа:** одна фича в `in_progress`. Скоуп не расширять без решения владельца.
3. **Завершение:** статус `passing` только после прогона команды проверки из реестра
   с сохранённым доказательством в `evidence/`.
4. **Передача:** обновить `CURRENT_STATE.md`, реестр, план. Записать выполненные команды
   и их результат, один следующий шаг.
